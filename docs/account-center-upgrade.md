# 账户与设置升级

2026-09-18。基于最新生产分支整合账户中心升级，发布到现有 Cloudflare Pages 与 Render 服务。

## 信息架构与界面

统一入口为 `/account`，旧 `/settings` 自动转到 `/account?section=preferences`。
账户中心包含个人资料、登录与安全、语言与偏好、关联账户、监护人、数据与同步、高级设置七个分区。桌面使用侧栏与内容区域，手机使用横向分区导航；保留站点原有品牌与导航。

审计发现并处理：账户与设置重复入口、地区字段重复、密码仅修改本地缓存、设置页暴露过多服务配置、搜索双重交互、React 文案被旧渲染器覆写、深色原生选择框对比度不足。高级服务配置移至独立分区。

顶部搜索统一为命令面板，支持设置关键词直达、键盘选择、中文输入法保护、焦点约束与关闭后的焦点恢复。账户中心另有设置专用搜索。分区切换保留未提交草稿。

## 数据与身份

- 名称、头像、毕业时间、备考方向、地区、语言、主题和公开主页关联通过账户 API 保存。旧的本地备考方向会在保存资料后迁移。
- 顶部主题开关与偏好设置共用账户偏好；重新登录、刷新后恢复账户设置。
- 云端保存成功后才更新本地。请求期间切换账户不会把结果写入下一账户；训练备份导入也检查当前账户。
- `POST /api/auth/change-password` 验证当前密码并更新服务端凭证，其他设备会话失效。保留纯本地账户的本地密码管理。
- 修改本地邮箱账户的邮箱需验证当前密码，并重新计算与邮箱相关的密码哈希；后台 `/sync` 不能修改邮箱、账户 ID 或登录提供方。
- 客户端不能修改订阅权限与 Google 身份关联；资料保存、同步与 Google 重新登录保留服务器管理的关联信息。Google 登录邮箱及已关联 Google 的本地邮箱不直接修改。
- 更换 Cloud API 地址会清除旧会话，避免将旧令牌发送到新服务。
- 资料与设置保存不再触发训练打卡。手动同步等待正在进行的请求，并继续同步期间新增的修改。

发布版本沿用已有 LeetCode 关联服务：支持中国站公开主页关联、公开统计及近期通过记录同步、更换账号和解除关联；保留已有模块、扩展导入和复习记录。无需提供 LeetCode 密码。它与登录凭证和个人备考存储分别管理。

云端登录验证、过期会话恢复和本机账户启用云同步沿用生产版本的现有实现。

## 监护人与备份

监护人入口集中到独立分区，保留现有授权与撤销机制，并补充重置监护码的影响提示和确认。

训练日志、笔记与原有进度使用现有备份格式；导入缺少字段的旧文件不会清空当前记录。日历、Mental Math 与 Daily Mock 通过当前账户的个人备考数据存储单独同步与备份，使用训练页共享的存储实例，导入仅接受所属账户的有效备份。

危险清空操作需要输入 `CLEAR`，明确提示可能同步清空云端训练日志；独立的日历、速算与 Daily Mock 备考记录保留。

## 发布说明

前端与 `api-server/server.py` 配套发布，新增资料保存在现有 `account_json`，无需数据库结构迁移。现有密码修改接口继续轮换当前会话并使其他会话失效。
