产品设计 · UI ROADMAP

QuantGym UI
升级与优化计划

在已完成的「总览」旗舰页与「Playful Precision」设计系统之上，把同一套质感、节奏与游戏化推广到全站的完整方案。

16 待迁移模块 5 阶段 6 大板块
现状 STATUS

「总览」已完成新系统并逐板块精修；其余 16 个功能页仍是旧界面或占位。视觉语言、组件、动效尚未沉淀为可复用体系。

目标 GOAL

统一质感与手感、强化游戏化动机、补齐移动端与深色模式，并沉淀一套可复用的组件与令牌库，让后续每个页面都「快而稳」。
