## 二、UI 现状总结

**完成度**：真实产品 21 个路由全部有对应设计稿，另加真产品没有的「联赛」增量模块。四轮迭代覆盖：视觉系统 → 深色模式+响应式 → 跨模块联动 → 游戏化+系统级打磨。

**做得好的**：
1. **一套令牌贯穿全站** —— 所有模块共用同一组 CSS 变量，深浅色一键切换无死角；字体、圆角、阴影、按钮 3D 按压感完全一致
2. **不是静态稿，是活的系统** —— qg-state 让 24 个界面共享一份 XP/连胜/任务数据：做完速算，总览打勾、计划看板挪卡、联赛涨分、通知入流，一条链全通
3. **游戏化有闭环** —— XP→等级→段位→联赛→训练币→商店→冻结卡→保连胜，每个数字都有去处
4. **移动端是真适配** —— 底部 Tab、单栏聊天、题库降密度、牌桌缩放，不是简单缩小
5. **情感层完整** —— 16 张吉祥物图各司其职（升级/连胜/失败/空状态/商店），Toast/庆祝弹窗全站可用

**已知局限**（设计稿性质决定）：
- 数据多为演示种子；联赛对手、PK 对手为静态/概率模拟
- 阅读器是排版示意，非真 PDF 渲染；语言切换只记偏好未翻译文案
- 深色模式下个别第三方色块（书封、公司 logo 底色）对比度未逐一校准
