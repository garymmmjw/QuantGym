# QuantGym 吉祥物系列 — GPT 图片生成任务书

## 使用方法

1. 每次对话都**先上传参考图**：修复好的吉祥物主体图（白色针织头巾版）。
2. 复制下面的「基础设定」+ 你要的那条「动作 Prompt」，一起发给 GPT。
3. 一次只生成一个动作，效果最稳。
4. 生成结果按对应的**文件名**保存，全部完成后丢进项目 `assets/` 文件夹。

---

## 基础设定（每条 Prompt 前面都要带上）

> 严格使用附件中的角色：绒毛质感 3D 鲨鱼吉祥物，白色针织运动头巾上有紫蓝色刺绣 Q，淡紫色 QuantGym 连帽卫衣 + 运动短裤，大蓝眼睛、粉腮红。保持设计、材质、比例、光照完全一致，全身入镜。输出**真正带 alpha 通道的透明背景 PNG**（如果做不到透明，就用纯白 #FFFFFF 纯色背景，绝对不要画棋盘格假透明）。竖幅约 1100×1400。除服装上的「Q / QuantGym」外，画面中不要出现任何其他文字。

## 动作系列

★ = 当前 UI 正在使用旧素材、优先替换

### 1. ★ 举奖杯 — `mascot-trophy-v2.png`
用于：排行榜、成就徽章

> 动作：双手高举一座金色奖杯庆祝，奖杯正面有 Q 标志，开心大笑，身体微微后仰，充满胜利感。

### 2. ★ 按计算器 — `mascot-calculator-v2.png`
用于：Mental Math 速算

> 动作：认真地按一台灰色计算器，一只手指按在按键上，若有所思的专注表情。

### 3. ★ 讲课指图表 — `mascot-teacher-v2.png`
用于：课程、能力值分析

> 动作：像小老师一样拿着教鞭，指着旁边一块画着上涨柱状图的淡紫色小白板，表情自信耐心。

### 4. ★ 火焰冲刺 — `mascot-fire-v2.png`
用于：连胜 streak、激励弹窗

> 动作：握拳向斜上方冲刺，身后跟着一道橙色火焰轨迹，表情热血斗志满满。

### 5. ★ 敲笔记本 — `mascot-laptop-v2.png`
用于：题目、资料笔记

> 动作：盘腿坐在地上，膝盖上放一台灰色笔记本电脑，专注敲代码，微微低头。

### 6. 面试装 — `mascot-interview.png`
用于：模拟面试

> 动作：卫衣外系一条正式的深蓝色领带，手拿一个文件夹，站姿挺拔，自信微笑。

### 7. 打扑克 — `mascot-poker.png`
用于：Poker 决策训练

> 动作：一只手拿着两张扑克牌（黑桃 A 和红心 K，牌面朝外），面前放着几摞筹码，自信地挑眉。

### 8. 挠头鼓励 — `mascot-oops.png`
用于：答错提示、空状态

> 动作：不好意思地挠着头巾，微微歪头，眼神温暖带着鼓励，嘴角一点点笑。

### 9. 撒彩带庆祝 — `mascot-levelup.png`
用于：升级、目标达成弹窗

> 动作：开心跳起，双臂张开，周围金色和紫色的彩带纸屑飞舞。

### 10. 睡觉 — `mascot-sleep.png`
用于：休息日、夜间模式

> 动作：抱着一个月亮形状的抱枕，闭眼熟睡，头巾依然戴着，姿态放松可爱。

### 11. 放大镜 — `mascot-search.png`
用于：搜索无结果

> 动作：双手举着一个大放大镜凑近看，透过镜片的那只眼睛被放大，好奇张望。

### 12. ★ 头像四连（胸像特写构图，分 4 次生成）
用于：聊天 / 论坛 / 人脉的头像

> 构图统一改为：胸像特写（头部和肩膀），面向镜头微侧。

- 开心大笑 → `avatar-happy-v2.png`
- 专注思考（手托下巴）→ `avatar-focused-v2.png`
- 眨眼 wink → `avatar-wink-v2.png`
- 惊讶张嘴（wow）→ `avatar-wow-v2.png`
