# 个人申请备考

登录后从左侧「个人备考」进入训练日历、Technical Interview 或 LeetCode。Mental Math 位于训练导航及个人备考页顶栏。手机底部提供日历、LeetCode、速算和题目入口，完整导航菜单中也可进入 Technical Interview。

## Behavioral Interview

`/behavioral-interview` 是每个账户自己的题库。新账户没有预置题目或示例答案；使用「添加题目」输入自己的题干和可选答案，之后可修改题干、自动保存答案或删除题目。题干最多 4,000 字符，答案最多 20,000 字符。`/behavioral` 是兼容入口。

题干保存在可选的 `behavioralQuestions` 中，答案继续保存在 `behavioralAnswers` 中，两者均使用当前登录账户的私有存储和同步接口。切换账户不会带入前一个账户的内容。同一账户旧版已保存的答案（包括明确清空的答案）会恢复为个人题目；不会给新账户复制旧题库或 BofA 示例。

删除使用永久删除标记，旧设备或旧客户端不能将题目复活；原有练习历史仍保留。服务器按当前登录凭证确定归属，不接受客户端指定其他所有者。云端需和网页一起发布；旧客户端缺少新字段时仍保留已有个人题目。

## 训练流程

- `/calendar`：左右滑动日期，查看量化题、心算、数列与图形推理的正确题数及试次数，以及 Technical Interview、LeetCode 和 Behavioral。支持日期跳转、近七天统计、补记与撤销。按设备本地日期归档，不把缺少完成日期的旧总数虚构为历史记录。
- `/leetcode`：保留原有 LeetCode 账户同步、题目和练习功能。独立 Coding OA 页面及导航入口已移除，原 `/coding-oa` 地址及旧 `#coding-oa` 书签重定向至 LeetCode。
- `/technical-interview`：独立的一题技术面试练习，从紫皮书题库中抽取题目，作答后记录复盘。
- `/daily-mock` 已停用，并重定向至 `/leetcode`；旧 `#daily-mock` 书签也转到 LeetCode。历史训练记录和备份继续保留，在日历中以「历史综合训练」显示已有完成记录，不再提供新建整套训练的入口。
- `/tools`：提供 Math Trainer、Sequence Trainer、Pattern Trainer 三个训练模块，分别保存试次、逐题明细、得分曲线和个人纪录。保留原有 QuantGym 界面风格，在现有训练页面中切换模块。
- `/poker` 及旧 Poker 导航已转向训练日历；原有 Poker 数据保留。

编程练习统一从 LeetCode 进入；移除 Coding OA 不修改 LeetCode 功能、通过题数或提交次数，也不删除已有编程复盘、草稿和备份数据。

Technical Interview 一次固定一道题，支持计时、自动保留草稿、参考思路和完成自评。点击「我做完了」后才会创建对应的日历记录；重新抽取保留之前的草稿，可从右侧历史记录继续。

紫皮书从现有归档文件经登录验证的 `/api/practice/technical/questions` 加载，目前筛选出 97 道具有文本题面和参考解答的技术题。源文件、版权清单和公共题库开关保持原样，题目不会打包进公开网页资源；题库不可用时显示重试状态，不以其他书籍或内置题目替代。

## Mental Math 三种训练

| 模块 | 内容与设置 | 作答方式 |
| --- | --- | --- |
| Math Trainer | 保留心算速算，可调整时长、加减乘除及各运算的数字范围。 | 输入正确答案自动切题；保留显式错误提交、跳过和到期记录，支持手机数字键盘及正负号切换。 |
| Sequence Trainer | 数字、英文字母或混合序列；基础、进阶、挑战三级，时长可调。每题给出 6–8 项，填写下一项。规则包括等差、等比、递增差分、交错、递归及字母步进等。字母按 A–Z 循环，Z 后回到 A，题面会提前说明。 | 点击「提交答案」或按 Enter 提交；每题只有一次作答机会，答对计 1 题。提交后显示正误、正确答案及中英文规律解析，点击「下一题」继续。 |
| Pattern Trainer | 3×3 图形矩阵缺少右下角一格，从 A–F 六个选项中补全。基础、进阶、挑战三级，时长可调。规律包括旋转、数量变化、形状或填充循环、位置移动、位置叠加，以及去掉重合位置；复杂题可组合多个规律。 | 选择选项后显式提交，每题提交一次；提交或跳过后显示答案、图形和规律解析，再进入下一题。 |

三个模块每次开始前都有 **5 秒准备倒计时**，准备时间不占正式训练时长，也不计入首题耗时。准备期间可以取消；进入正式训练后，可完成试次或提前结束，再切换模块。

数列与图形训练在查看反馈和解析期间，**整轮倒计时继续运行**。已经提交的题目耗时固定；点击「下一题」时，新题的单题计时从零开始，解析阅读时间不计入下一题。刷新、切换页面或暂时离开后，准备阶段、当前作答或反馈状态会恢复，计时依据原定截止时间继续，不会因刷新重新获得训练时间。到期未提交的题目保留为未完成，不计正确分数。

每个模块的 Attempt 曲线只包含完整结束的试次，每次试次一个点，分数为正确题数，保留 0 分记录。模块之间的曲线、历史和个人纪录独立；筛选可选全部设置、当前设置或某组历史设置，时间范围可选全部、近 30 天或近 90 天，横轴可选试次或日期。试次编号按该模块完整历史固定，筛选后不重新编号。支持选择历史试次复盘、复用该次设置和导出 CSV。

个人纪录始终只比较相同设置：心算比较时长、运算和数字范围；数列比较时长、难度和序列类型；图形比较时长和难度。提前结束仍保留逐题记录与已答对的训练量，但不进入完整试次曲线或个人纪录。日历分别统计心算、数列和图形的正确题数。

数列题型参考 [NeetQuant 的序列训练说明](https://neet-quant.com/simulators/sequences)，矩阵题型参考 [Mensa Australia 的练习说明](https://www.mensa.org.au/membership-information/practice-tests/practice-tests)及 [Mensa IQ Challenge](https://www.mensa.org/mensa-iq-challenge/)。这里的题目和解析均为项目内原创生成练习，并非 NeetQuant 或 Mensa 的官方题库，也不采用其官方评分标准。

## 记录保存

每次编辑先在浏览器按账户保存。有效云端登录会自动将记录同步到账户；页面显示「已保存到你的账户」后表示服务器已确认保存。离线或登录过期时显示状态并保留本机副本，恢复网络或重新登录后可重试。

Technical Interview 与 LeetCode 页面共用当前账户的个人记录。已有 Coding OA 完成记录保留，并继续兼容 LeetCode 原有随机抽题权重；同时显示多个读取组件时，只保留同一账户、同一登录凭证的一条云端同步流程。

独立练习保存在可选的 `practiceSessions` 集合中，兼容旧版备份，不需要新增数据库表。相同试次保留最新草稿，已完成状态不会被旧草稿覆盖；较旧客户端漏传新集合时，服务端仍保留原有练习和删除标记。

服务端新增私有 `/api/personal-prep` GET / PUT 与 `user_personal_prep` 表，支持 SQLite 和 Postgres。所有读取与写入都从登录令牌确定账户；不接受请求指定记录所有者，不加入社群、公开资料或排行榜数据。响应禁止共享缓存。

云端更新使用版本比较，检测其他设备的新记录后合并重试。备份恢复和云端合并保留已完成题目及终态试次；撤销补记以删除标记同步。个人记录可随时导出和恢复 JSON 备份。服务端单个快照限制为 8 MiB；浏览器容量不足会明确提示，保留已保存副本与当前内存记录。

三模块沿用现有个人记录和备份格式，兼容没有模块标记的旧心算存档：旧试次仍归入 Math Trainer，原有得分、逐题耗时及个人纪录保持可读。新增数列与图形记录按模块保存，不将旧记录转换成新模块数据，也不清空原有训练历史。

## 验证

```sh
npm run test:personal-prep
python3 scripts/test-personal-prep-api.py
python3 scripts/test-personal-prep-api.py --postgres
npm run check:route-integrity
npm run build
```

Postgres 验证模式使用独立临时数据库及端口，测试结束自动清理；运行环境需要 PostgreSQL 工具与项目声明的 psycopg 依赖。接口测试使用测试账户，不读取或修改现有用户训练数据。

浏览器回归覆盖补记、刷新恢复、限时速算、历史图表、手机布局、跨独立浏览器存储同步及撤销同步。移除 Coding OA 的回归还需覆盖桌面和手机导航、Technical Interview、LeetCode、两个旧入口重定向和已保存历史记录。发布版本应核验 `/version.json`；涉及 API 更新时，还需核验接口认证边界及数据库健康状态。本次移除页面不改变 API 或存储格式。

三模块更新已验证：154 项个人备考测试、23 条路由检查、严格生产构建，以及 SQLite / Postgres 各 14 项真实 HTTP 存取测试。独立浏览器测试账户验证了三模块准备倒计时、取消、作答、反馈刷新恢复、到期保存、模块独立历史及日历计数；图形模块另验证了 390px 手机宽度和切题键盘焦点。此更新沿用现有 API，无需新增服务端表或迁移旧数据。

## 准备统计口径

- LeetCode 日历、总览、活跃度和 Stage 使用同一条通过记录时间线。同题距上一次计入的 AC 至少 3 小时可再次计为 1 题；跨日或跨 Stage 不重置间隔，间隔内的 AC 不移动计数锚点。
- 累计值为可核验完成次数，加上可信账号累计不同题数中尚缺明细的首次完成数量。历史不完整时这是下界，以 ≥ 标识；缺日期的部分不会产生每日积分或被分配到 Stage。
- Behavioral 保存非空答案即准备 1 题，无需额外确认。同一次连续编辑只计一次，后续独立编辑会保留新的练习记录；清空答案不新增计数，不移动已有历史日期。旧答案沿用可信历史日期，缺日期时不补成今天。

## 私有工作区

部署默认开启 `QUANTGYM_PRIVATE_WORKSPACES=1`。个人题目、答案、投递记录、计划、笔记及练习进度按账户归属；Technical Interview 题库内容共用，个人作答及记录仍私有。

社群发布、题目评论与点赞、排行榜、多人功能和监护访问在私有模式下停用，包括服务端接口和监护通知。旧共享记录不删除、不继续公开；旧客户端的普通账户同步不会重新发布它们。关闭该配置会恢复旧共享行为，只用于明确需要旧行为的环境与测试。

未标明所有者的历史本机笔记和计划标记不自动归给下一个登录账户，原始本机记录保留。新笔记按账户区分。上传媒体的接口要求所有者登录，响应禁止共享缓存；头像由当前登录凭证读取，不把凭证写入链接。
