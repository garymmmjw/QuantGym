# 个人申请备考工作台

登录后的首页 `/` 是「今日工作台」：继续未完成的 Daily Mock、查看当天完成量、近七天训练、到期复习和申请的下一步。桌面侧栏按训练与申请资料组织入口；手机底部提供今天、训练、日历、复习、申请五个入口。搜索可用 `⌘ K` / `Ctrl K` 打开。

## 训练与复习

- `/calendar`：横向滑动日期，查看量化题、速算正确题数及试次数、Tech、Coding、Behavioral 和完成的 Daily Mock 轮数。支持前后日期、按周浏览、日期跳转、回到今天、近七天统计，以及线下训练补记与撤销。整套完成不会重复计入题目总数，复习也不会冒充一次新的原题完成。
- `/daily-mock`：默认 120 秒速算、3 道技术题、3 道编程题、1 道行为题。可调整题量和时间预算，或关闭部分板块。开始后保存题目快照与回答草稿，可以分次完成；返回历史记录不会重新出题。技术题可选当前题库或基础练习，题源允许时会避开最近几轮的题目。`/daily-mock?session=…&question=…` 可打开已保存的具体题目。
- `/tools`：速算答对自动切题，支持时长、运算和数字范围设置。保存每题耗时、显式错误提交、跳过及到期状态；显示当前和过去五次同设置试次的散点图、逐题明细及个人纪录。提前结束仍记录已完成训练量，但不计入个人纪录或 Daily Mock 速算板块的完成判断。离开页面不会暂停速算的到期时间。
- `/review`：已完成且自评为「需要复习」或「借助提示完成」的 Daily Mock 题目进入复习清单，同一稳定题目 ID 只安排一项。先重新回答，再揭示参考答案与原回答；选择「还需再练」「基本掌握」「独立讲清」后，分别安排在明天、3 天后、7 天后。支持待复习和全部筛选。复习结果及新笔记独立保存，不改写原回答；新的薄弱作答会重新进入待复习。

技术、编程、行为题由本人填写回答并自评。编程题提供题意、约束、示例与 Python / JavaScript / C++ 参考解法；目前没有代码执行或自动判题。复习输入框中的新回答在选择复习结果前，只保留在当前页面。

日历仅使用可靠的完成日期：新训练事件、旧题目的 `completedAt`、旧速算的 `createdAt`、按账户保存的面试逐题训练条目。缺少日期的旧记录不会按当前总数摊入历史，可自行补记。日期与复习间隔按设备本地时区计算，因此跨时区查看同一时间点时，所属日期可能不同。

## 真实申请追踪

`/applications` 保存本人填写的真实申请：公司、岗位、地点、职位链接、申请阶段、截止日期、下一步行动及日期、备注。阶段包括准备投递、已投递、笔试 / OA、面试中、已获 Offer、未通过、已撤回；支持搜索、阶段筛选、编辑、归档及恢复。

岗位列表中的「加入申请追踪」会预填公司和职位信息，需要点击「保存申请」才会成为一条记录。申请表单未保存前的内容只保留在当前页面。已保存的日期会参与今日工作台的下一步列表；本功能不会代投简历、读取邮箱、自动核实申请状态，也不会发送邮件或系统提醒。没有记录时显示空态，不生成示例申请。

## 保存范围与跨设备继续

| 数据 | 保存与同步范围 |
| --- | --- |
| 新版速算设置、试次及逐题耗时 | 浏览器按账户保存；连接同一云端账户后自动同步。正在计时的试次仍按原到期时间恢复。 |
| Daily Mock 设置、题目快照、回答草稿和完成记录 | 浏览器按账户保存，并通过个人备考同步跨设备继续。 |
| 日历补记、撤销标记、已保存的申请及复习结果 / 笔记 | 属于同一份个人备考数据，随账户同步。申请表单、尚未评分的复习输入除外。 |
| 题库完成状态、收藏、旧速算记录及面试逐题训练条目 | 仍由旧版账户状态同步处理；日历可只读汇总有日期的记录。个人备考页的同步状态不代表所有旧模块均已同步完成。 |
| 题目详情中的个人笔记 | 按账户保存在当前浏览器，尚未接入跨设备云同步。 |
| 旧版 `/interview` 模拟面试的进行中草稿、完整会话历史及恢复列表 | 按账户保存在本机，尚未接入个人备考云同步；与已同步的逐题训练条目不同。 |
| 下载的 JSON 备份文件 | 保存到下载位置，不会因下载而自动上传；导入相应备份后才恢复记录。 |

个人备考每次持久化先写本机副本，有效云端会话再自动同步。页面显示「已保存到你的账户」表示服务器已确认这份个人备考数据；「已保存在本机」「等待云端同步」「云端登录已过期」均不能视为已完成跨设备保存。联网、重新聚焦页面或点击「立即同步」可触发重试。

云端使用版本比较处理同时编辑。合并会保留已完成题目、进度更完整的速算记录及终态试次；补记撤销使用删除标记。申请与复习采用独立事件记录，备份或同步不应删除已有事件。同步用于设备之间接续与合并记录，不保证两台设备同时答同一道题时保留两份独立答案。

个人备考页底部的「导出备份 / 恢复备份」覆盖上述新版训练、申请和复习数据，只接受相同账户与兼容版本；它不是整个网站所有本机内容的备份。恢复按记录合并，不以旧快照覆盖当前完成进度。无效文件或账户不匹配会被拒绝。服务器单个个人备考快照上限为 8 MiB。出现本机保存失败提示时，当前内容可能仅在页面内存中，应保持页面打开，重试或先导出备份。

## 登录恢复与旧记录认领

在个人备考状态栏点击「恢复账户同步」，可用当前账户邮箱和密码重新验证。这个操作只更新同一账户的云端会话，不替换训练记录；返回了不同账户，或验证期间切换了账户，会拒绝接入。Google 账户可返回登录页使用 Google 重新登录。恢复同步不能把一个本地账户的记录自动转移到另一个云端账户。

账户资料更新只允许姓名、地区、毕业时间、头像等可编辑资料。邮箱修改需要尚未实现的验证流程，目前会被拒绝；账户 ID、登录方式、Google 身份、角色和订阅信息由服务器保留，客户端不能借资料修改取得管理员权限。

新题目笔记、面试草稿与历史按账户隔离；切换账户不会把上一账户的当前草稿显示给下一账户。旧版本留下的无账户标识记录不会因下一次登录而自动判定归属：

- 题目详情中如出现「恢复旧版笔记」，仅在确认属于本人时点击「这是我的笔记，合并到当前账户」。现有笔记与旧原始记录均保留。
- 模拟面试中的「恢复旧版面试记录」可由本人确认后合并历史并列出恢复草稿；「备份当前进程并打开」会先保存当前进程，再打开所选旧进程。明确属于其他账户的记录不会导入。
- 无归属的旧整份训练状态不会自动迁入当前账户。现有原始数据保留，不应把“没有显示”理解为已删除或已完整迁移。

旧模块写入失败时会提供「重试保存 / 导出未保存记录」。此类文件使用独立的「恢复本机训练备份」入口，仅恢复当前账户：题目笔记合并、面试草稿加入恢复列表；整份训练状态存在不同版本时保留当前版本并提示冲突，不静默覆盖。它与个人备考页底部的 JSON 备份格式不同。

## 隐私边界

新增 `/api/personal-prep` GET / PUT 和 `user_personal_prep` 表支持 SQLite、Postgres。服务端从登录令牌确定数据所有者，不接受请求指定其他账户；个人训练答案、申请和复习事件不加入社群、公开资料或排行榜。接口响应禁止共享缓存，写入提交完成后才确认成功。

**个人工作台并不意味着全站已经私有化。** 当前前端收起了社群、消息、排行榜等扩展模块；旧路径会显示返回工作台的提示，`/poker` 转向日历，原始数据保留。收起入口没有撤销原有后端接口或静态资源的访问权限：

- `/api/leaderboard` 仍可匿名读取昵称、地区、头像、旧训练技能统计等排行榜信息；新版个人备考记录不在该查询中。
- `/api/community` 仍可匿名读取原有共享社群内容。旧 `/sync` 也保留社群同步分支，不能用它代替私有笔记存储。
- `/api/problems` 匿名请求仍返回公开题库，登录后还可返回本人上传的题目；公开题库与打包进网页的静态内容不会因为登录页或个人导航而自动变私有。

本次改动没有重新审定既有题库内容的发布权利或完成全站访问控制改造。需要收回公开资料或题库时，必须另外处理后端权限、已发布静态文件及部署配置，不能只隐藏导航。

## 验证与发布核对

使用项目要求的 Node.js 版本与 Python 环境执行：

```sh
npm run test:personal-prep
python3 scripts/test-personal-account-api.py
python3 scripts/test-personal-prep-api.py
python3 scripts/test-personal-prep-api.py --postgres
npm run check:route-integrity
npm run build
```

账户回归测试覆盖邮箱提权阻断、嵌套权限输入、服务器元数据保留、密码登录、账户隔离、失败回滚及提交后恢复。个人备考接口测试另覆盖认证、事件保留和并发版本处理。测试使用隔离临时数据库与测试账户，不读取或修改现有用户训练数据。Postgres 模式需要 PostgreSQL 工具及项目声明的 psycopg 依赖。

发布时网页与 API 都应更新。核对网页 `/version.json`、API `/api/health` 的 `releaseCommit` 与目标提交，以及数据库健康和匿名 / 跨账户边界。`releaseCommit` 仅在部署环境提供合法的 40 位提交标识时有值，本地可能为 `null`。浏览器验收仍需确认桌面和手机上的完整训练、申请日期保存、复习、刷新恢复、旧记录认领及独立浏览器间同步；测试命令通过不能替代实际部署验收。
