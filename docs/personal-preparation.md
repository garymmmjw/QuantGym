# 个人申请备考

登录后从左侧「个人备考」进入训练日历或 Daily Mock。Mental Math 位于训练导航及个人备考页顶栏。手机底部提供日历、Daily Mock、速算和题目入口。

## 训练流程

- `/calendar`：左右滑动日期，查看量化题、速算正确题数及试次数、Tech、Coding、Behavioral 和整套 Daily Mock。支持日期跳转、近七天统计、补记与撤销。按设备本地日期归档，不把缺少完成日期的旧总数虚构为历史记录。
- `/daily-mock`：默认 120 秒速算、3 道技术题、3 道编程题、1 道行为题。可调整数量、时间预算，或关闭部分板块。题目与作答草稿在开始后固定保存，可分次完成。技术题优先选用当前题库中带解答的题，缺少时使用内置基础练习。
- `/tools`：输入正确答案自动切题。时长、运算及数字范围可调，记录每题耗时、显式错误提交、跳过及到期状态。支持历次 Attempt 得分曲线（每次完整试次一个点），按设置、日期范围筛选，横轴可选试次或日期，并可导出 CSV。逐题耗时保留在明细，个人纪录按当前相同设置统计；支持复用历史设置、手机数字键盘及正负号切换。提前结束保留已完成训练量，但不参与个人纪录或 Daily Mock 完成判断。
- `/poker` 及旧 Poker 导航已转向训练日历；原有 Poker 数据保留。

编程题提供题意、约束、示例和 Python / JavaScript / C++ 参考解法。本版不执行用户代码或自动判题；技术、编程、行为题由使用者填写回答并自评后完成。

## 记录保存

每次编辑先在浏览器按账户保存。有效云端登录会自动将记录同步到账户；页面显示「已保存到你的账户」后表示服务器已确认保存。离线或登录过期时显示状态并保留本机副本，恢复网络或重新登录后可重试。

服务端新增私有 `/api/personal-prep` GET / PUT 与 `user_personal_prep` 表，支持 SQLite 和 Postgres。所有读取与写入都从登录令牌确定账户；不接受请求指定记录所有者，不加入社群、公开资料或排行榜数据。响应禁止共享缓存。

云端更新使用版本比较，检测其他设备的新记录后合并重试。备份恢复和云端合并保留已完成题目及终态试次；撤销补记以删除标记同步。个人记录可随时导出和恢复 JSON 备份。服务端单个快照限制为 8 MiB；浏览器容量不足会明确提示，保留已保存副本与当前内存记录。

## 验证

```sh
npm run test:personal-prep
python3 scripts/test-personal-prep-api.py
python3 scripts/test-personal-prep-api.py --postgres
npm run check:route-integrity
npm run build
```

Postgres 验证模式使用独立临时数据库及端口，测试结束自动清理；运行环境需要 PostgreSQL 工具与项目声明的 psycopg 依赖。接口测试使用测试账户，不读取或修改现有用户训练数据。

本次验证还覆盖实际浏览器中的补记、刷新恢复、限时速算、完整 Daily Mock、历史图表、手机布局、跨独立浏览器存储同步及撤销同步。发布版本应在网页及 API 都更新后，核验 `/version.json`、接口认证边界及数据库健康状态。
