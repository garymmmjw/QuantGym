`389b770410cc0b7c21c85673bfa2077420fe7f65`:

- `PlusJakartaSans[wght].ttf` — upstream SHA-256
  `89b3fb38aa0d275d7a731d0d817a4f1622b316b4d7fbdedcf02ee9099ff68bc8`

were converted with fontTools 4.51.0 and Brotli compression; no text characters were removed.
